# veripaper（工作名，可改）

开源学术论文工具：**论文只是一个最终呈现。**

研究人员只做三件事：**创意想法、逻辑推演、数据证明**。
其余全部——写作呈现、对标评价、投稿决策、返修沟通——由工具接管。

```
idea → 开题决策 → 立意提炼 → 证据锚定 → 顶刊对标 → 审稿人模拟 → 投稿决策 → 返修沟通 → publishable
```

## 与 OpenDraft 的区别

OpenDraft（19 agents，MIT）解决"10 分钟写出初稿"，强项是引用**存在性**验证。
它自己承认：*"verifies sources exist, not that claims about their content are accurate."*

veripaper 解决"发出去"：
- **论点级核验**：不只查引用存在，还查"被引文献真支持你的论点吗"
- **想法优先**：起点是你的粗糙想法，帮你提炼学术价值（新颖性/贡献声明）
- **审稿人模拟**：投稿前按期刊口径挑刺，专盯证据缺口和过期数据
- **返修沟通**：逐点回复信生成 + 修改追踪

## 铁律

1. 所有引用必须来自真实检索返回，**禁止模型编造引用**。
2. 标签诚实：`[VERIFIED]` / `[CITED]` / `[UNVERIFIED]` / `[STALE:YYYY]` ——
   宁可降级，不许假装核验过。
3. 工具辅助写作，不替代研究；最终判定权永远在作者。

## 快速开始（v0.1）

```bash
pip install -e .
python -m veripaper ground draft.md --out report.md
```

输入论文 markdown，输出逐条核验报告。
